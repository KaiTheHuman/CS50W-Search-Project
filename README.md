# CS50W Search Project

A recreation of Google's search interface built as part of Harvard's CS50's Web Programming with Python and JavaScript (CS50W) course.

The project includes three search pages:

Google Search – A standard search interface that redirects queries to Google.

Google Image Search – Allows users to search for images using Google's image search.

Google Advanced Search – Provides multiple search fields for creating more specific Google searches.

# Features

Google-inspired search interface

Advanced search with multiple query parameters

Navigation between search pages

Responsive and styled user interface

This was my first project for CS50W and focused on building functional web interfaces using HTML and CSS while recreating the layout and behaviour of familiar Google search pages.
